Privacidad

Esta versión estática no usa cuentas, publicidad, analítica propia ni acceso a la geolocalización. Las búsquedas se procesan en el navegador.

GitHub Pages puede registrar datos técnicos necesarios para prestar el alojamiento conforme a sus propias políticas. Los enlaces externos redirigen a servicios ajenos.

Una caché técnica mediante service worker puede almacenar páginas públicas visitadas. Puedes retirar esos datos desde el navegador.

Las propuestas de lugares se realizan en GitHub Issues, donde son públicas. No compartas documentos de identidad, teléfonos privados, domicilios ni coordenadas sensibles. No disponemos todavía de un formulario privado de registro ni de un sistema de eliminación de cuentas.

Antes de activar cuentas, formularios directos o analítica se publicará una política completa de datos y un canal responsable de derechos.

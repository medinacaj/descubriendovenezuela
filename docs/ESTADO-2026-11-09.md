## Evidencia externa y límites persistentes

- Las 196 fotografías pendientes necesitan imágenes del lugar exacto y licencia compatible. Se muestra una ausencia explícita, sin completar con imágenes falsas ni fotos de otro destino.
- La verificación de accesos, seguridad, precios, contactos y operación de establecimientos requiere evidencia actual y autorización cuando corresponda. No se transforma investigación documental en visita de campo.
- Las métricas de usuarios reales necesitan tráfico de producción. Las pruebas de laboratorio y axe no certifican WCAG ni Core Web Vitals de campo.
- Publicar la aplicación con servidor requiere un entorno Node/PostGIS y sus controles operativos. GitHub Pages sirve el catálogo estático y no expone administración ni base de datos.
- La integración del PR y la configuración de Pages son acciones de publicación distintas de implementar código. Solo se consideran cerradas después de observar su resultado remoto.

Las menciones históricas a roles adicionales, anuncios, pagos, carga de archivos y otros productos describen una hoja de ruta; no son capacidades existentes ni requisitos añadidos a esta entrega.

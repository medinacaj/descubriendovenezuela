# Acceso para investigación turística

El usuario autorizó investigar fuentes públicas y cargar fichas documentadas. La red actual permite GitHub pero bloquea las fuentes turísticas. El intento de guardar la ampliación devolvió `draft_not_editable`; no se confirmó el guardado ni cambió la red de esta sesión.

Desde los ajustes del entorno, abrir un nuevo chat de configuración para permitir los dominios de `research-network-request.json`, conservando los dominios y presets existentes. Si hay una publicación del entorno en curso, esperar que termine antes de editar su configuración. Aplicar los cambios mediante la interfaz del entorno y volver a comprobar el acceso real; guardar un borrador por sí solo no lo aplica.

Dominios iniciales solicitados: www.google.com, google.com, whc.unesco.org, www.inparques.gob.ve, www.venezuelatuya.com y venezuelatuya.com. Las webs oficiales de alojamientos concretos se añadirán según se identifiquen; esta lista no garantiza acceso a todas las fuentes futuras ni elimina posibles restricciones del sitio de destino.

Continuar luego con posadas reales: identificar negocio, contrastar web o canal oficial, documentar fuente/fecha y publicar solo campos corroborados. No copiar fotos, reseñas o tarifas caducadas. No es necesario que el usuario investigue ni seleccione establecimientos.
